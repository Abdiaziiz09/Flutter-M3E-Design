# Icons

Material's [icon guidance](https://m3.material.io/styles/icons/overview) covers consistent meaning and use. Flutter's `Icon` renders an icon from an `IconData`; it does not automatically supply every current Material icon asset or expressive variant.

- Use icons with established meaning and pair unfamiliar or essential actions with accessible labels.
- Keep icon size, alignment, optical balance, and color role consistent with component context.
- Avoid using shape or color alone to communicate a status or action.
- Verify availability/licensing of custom icon assets and include appropriate semantic labels.

Test icon clarity at actual display size, in light/dark themes, at large text scale, and with screen readers.
