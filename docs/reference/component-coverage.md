# Component coverage matrix

This matrix tracks component coverage at a glance. The [component verification ledger](component-verification-ledger.md) records each official source URL, what the 2026-10-24 source check actually exposed, the local SDK/API evidence, applicable states, visual scenarios, and remaining gaps. The [official Material visual reference gallery](visual-reference-gallery.md) embeds selected images directly from Material's hosting; these are design references, not Flutter screenshots. Material page metadata is not a substitute for reviewing the full visual specification.

Use these mapping labels consistently: **API verified** means the named Flutter Material API exists in the local SDK snapshot; it does not imply M3/M3 Expressive visual equivalence. **Composition only** means a pattern is assembled from building blocks rather than represented by a dedicated stock widget. **No direct API** means no equivalent Flutter Material widget is asserted. **Unverified** means component-specific design behavior or implementation evidence remains incomplete. Refer to the ledger for the meaning of its test status labels.
