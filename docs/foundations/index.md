# Design foundations

M3 Expressive should be used to make hierarchy and action more understandable, not to add decoration indiscriminately. Consult the relevant canonical pages:

- [Color](color.md): semantic roles, light/dark schemes, dynamic color limits.
- [Typography](typography.md): hierarchy, text scaling, font fallback.
- [Shape](shape.md): containers, shape emphasis, clipping.
- [Elevation and surfaces](elevation-and-surfaces.md): tonal surface roles versus physical elevation.
- [Spacing and layout](spacing-and-layout.md): composition, alignment, adaptive structure.
- [Icons](icons.md): meaning, labels, consistency, scaling.
- [Motion](motion.md): state changes, transitions, reduced motion.
- [Accessibility](accessibility.md): semantics, contrast, focus, target usability.
- [Responsive design](responsive-design.md): changing layouts with space and input.

**Verification method:** inspect the source and version notes for the exact requirement, then compare screenshots and test interactions at representative sizes, themes, text scales, and input modes. No single foundation value establishes compliance by itself.
