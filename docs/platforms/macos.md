# macOS

Follow [Flutter macOS setup](https://docs.flutter.dev/platform-integration/macos) and Apple's macOS Human Interface Guidelines.

- Account for resizable windows, menus, keyboard shortcuts, pointer precision, scroll behavior, focus, and system title bar conventions.
- Make explicit choices about Material styling versus macOS-native integration.
- Test VoiceOver, keyboard navigation, display scaling, dark mode, and window resizing.
- Verify plugins and notarization/distribution requirements separately from visual design.

Do not treat a responsive tablet layout as automatically suitable for a desktop window.
