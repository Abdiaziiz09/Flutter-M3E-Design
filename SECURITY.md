# Security policy

This repository is documentation and a small Flutter reference example. No security support SLA is currently established.

## Reporting

Do not publish credentials, personal data, or exploit details in an issue. Use GitHub's private vulnerability reporting for the actual repository if enabled; otherwise contact its maintainers privately using the contact information published on that repository. Do not invent or assume a repository owner or contact address.

For security-sensitive Flutter integration advice, cite primary platform and Flutter sources and note the versions covered. Report vulnerable third-party dependencies to their maintainers.
