# Windows

Flutter supports Windows desktop with platform-specific build prerequisites and integrations; see [Flutter Windows setup](https://docs.flutter.dev/platform-integration/windows).

- Design for resizable windows, pointer, keyboard shortcuts/focus, scroll wheels, and high-DPI displays.
- Avoid assuming bottom navigation or modal bottom sheets are the right desktop pattern; choose layout and navigation for available space and task.
- Verify title bar/window controls, system theme/accent integration, context menus, and file interactions independently.
- Test Narrator or other supported assistive technology, high contrast, text scale, and window resizing.
- Check plugin compatibility and native build requirements for the actual Windows release.
