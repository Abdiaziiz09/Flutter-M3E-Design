# Component catalog and coverage

This catalog identifies common Material components and their Flutter mapping. It does **not** assert that every component has an M3 Expressive-specific variant. Exact anatomy, token assignments, and behavior must be checked on the linked official component page; text-accessible source content and Flutter APIs may not provide a complete one-to-one mapping.

| Group | Canonical guide |
|---|---|
| Actions, app bars, navigation, tabs | [Actions and navigation](actions-and-navigation.md) |
| Cards, lists, selection, chips | [Content and selection](content-and-selection.md) |
| Inputs, dialogs, sheets, progress, feedback | [Input and feedback](input-and-feedback.md) |
| Button groups, split buttons, FAB menus, badges, dividers, side sheets, time pickers | [M3 Expressive component deep dives](expressive-component-deep-dives.md) |
| Source, SDK, state, and test evidence | [Component verification ledger](../reference/component-verification-ledger.md) |

The [component coverage matrix](../reference/component-coverage.md) tracks component mapping status; the [component verification ledger](../reference/component-verification-ledger.md) records checked source metadata, local SDK evidence, states, tests, and remaining gaps. The [M3 Expressive component deep dives](expressive-component-deep-dives.md) document less-covered topics. The [official Material visual reference gallery](../reference/visual-reference-gallery.md) embeds selected Google-hosted source images; those images are not Flutter output and do not prove conformance. These pages do not claim full M3 Expressive conformance.
