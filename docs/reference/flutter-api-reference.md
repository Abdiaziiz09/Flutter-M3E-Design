# Flutter API reference

API mappings are examples, not guarantees for every Flutter release. Verify the pinned app SDK's API documentation and run analyzer/tests before adopting a property or constructor.

| Need | Flutter API entry point |
|---|---|
| App-level Material theme | [`ThemeData`](https://api.flutter.dev/flutter/material/ThemeData/ThemeData.html), [`MaterialApp`](https://api.flutter.dev/flutter/material/MaterialApp-class.html) |
| Semantic colors | [`ColorScheme`](https://api.flutter.dev/flutter/material/ColorScheme-class.html) |
| Typography | [`TextTheme`](https://api.flutter.dev/flutter/material/TextTheme-class.html) |
| Navigation | [`NavigationBar`](https://api.flutter.dev/flutter/material/NavigationBar-class.html), [`NavigationRail`](https://api.flutter.dev/flutter/material/NavigationRail-class.html), [`NavigationDrawer`](https://api.flutter.dev/flutter/material/NavigationDrawer-class.html) |
| Inputs | [`TextField`](https://api.flutter.dev/flutter/material/TextField-class.html), [`Checkbox`](https://api.flutter.dev/flutter/material/Checkbox-class.html), [`Switch`](https://api.flutter.dev/flutter/material/Switch-class.html), [`Slider`](https://api.flutter.dev/flutter/material/Slider-class.html) |
| Animations | [Flutter animation guide](https://docs.flutter.dev/ui/animations) |
| Responsive constraints | [`LayoutBuilder`](https://api.flutter.dev/flutter/widgets/LayoutBuilder-class.html), [`MediaQuery`](https://api.flutter.dev/flutter/widgets/MediaQuery-class.html) |

The repository's sample intentionally uses a conservative subset. The API reference does not establish exact M3 Expressive visual or motion conformance.
