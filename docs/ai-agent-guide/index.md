Use the repository-root `AGENTS.md` before implementation. This guide is the operational checklist for applying the repository as a design-system reference.

- [Implementation workflow](implementation-workflow.md)

Agents must report source evidence, Flutter/platform versions, tests performed, custom deviations, and unresolved support questions. They must never infer full M3 Expressive compliance from a theme flag or screenshot resemblance alone.
