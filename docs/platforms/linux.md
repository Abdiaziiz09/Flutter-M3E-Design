# Linux

Follow [Flutter Linux setup](https://docs.flutter.dev/platform-integration/linux). Flutter desktop availability does not imply identical integration across distributions or desktop environments.

- Design for window resizing, keyboard/pointer input, scroll behavior, focus, and varied display scaling.
- Check packaging, plugin, accessibility, desktop portal, and system theme/accent capabilities for supported distributions.
- Treat dynamic system color support as package/environment dependent; provide tested fallback.
- Validate keyboard and assistive technology support on the actual distribution/deployment target.

Record tested distribution, desktop environment, Flutter version, and packaging method.
