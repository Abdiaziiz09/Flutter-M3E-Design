# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a respectful experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment include empathy, respectful disagreement, constructive feedback, and acceptance of responsibility. Unacceptable behavior includes harassment, personal attacks, intimidation, discrimination, and publishing private information without permission.

## Scope and enforcement

This code applies in project spaces and when someone represents the project. Report incidents privately to the repository maintainers through the contact route configured by the actual GitHub repository owner. Maintainers should review reports promptly, fairly, and confidentially, and may remove content or restrict participation as appropriate.

This short policy is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/); the project has not copied its full text. Configure a real reporting contact before public release.
