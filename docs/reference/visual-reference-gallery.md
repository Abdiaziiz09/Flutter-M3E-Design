# Official Material visual references

This gallery points to visual examples served by the official Material Design component pages. The image files are embedded from Google's hosting rather than copied into this repository. Each image links to its source page; availability and content may change upstream. Rights remain with the respective owner. Do not assume that a source link or attribution grants permission to download, modify, or redistribute the artwork.

These examples help compare design intent. They are not Flutter screenshots, token tables, or proof that a Flutter widget matches Material 3 Expressive. Follow the linked component page for context and verify the selected Flutter SDK, platform, and states independently.

## Using the gallery during implementation

- Compare component purpose, hierarchy, and overall form with the primary Material page.
- Do not infer exact measurements, colors, motion, or behavior from a compressed image.
- Check Flutter API behavior in the chosen SDK and record application-specific adaptations.
- Treat the repository's Flutter goldens as test-renderer regression fixtures only. They are not substitutes for the official references above or screenshots rendered with real platform fonts.
