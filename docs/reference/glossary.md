# Glossary

| Term | Meaning in this repository |
|---|---|
| Material 3 (M3) | The Material Design system and component/foundation guidance commonly represented in Flutter's Material library. |
| Material 3 Expressive (M3E) | Material 3 design direction emphasizing deliberate expressive tactics; not a separate Flutter mode or certification. |
| Semantic color role | A named color purpose such as `primary`, `surface`, or an associated `on*` role. |
| Responsive design | Adjusting layout to fit available space. |
| Adaptive design | Choosing a usable layout or interaction pattern for the available context and inputs. |
| Dynamic color | A color scheme derived at runtime from a platform/user source, where supported. |
| Official guidance | Claim directly supported by an official cited source. |
| Implementation recommendation | A repository/app choice not prescribed by the cited design source. |
| Conformance claim | A bounded assertion that specified requirements were checked; never inferred from theme configuration alone. |
